## Why

사용자는 현 시점에 이용 가능한 근거로 종목·ETF·현금과 비중을 끝까지 판단해 추천하고, 이를 반복하며 장기 투자 성과를 개선하는 도구를 원한다. 현재 흐름은 정량 순위와 투자자 합의를 비중으로 기계적으로 변환하며, 미검증 상태를 추천 회피의 이유로 해석하거나 편입 후보 부족을 현금 확대 결정으로 바꾸기 쉽다.

목표는 사용자 제약 안에서 장기 복리 성과를 높일 최선의 선택을 매번 제시하는 것이다. 미래 수익 보장이나 과거 성과 입증은 현재 판단의 전제 조건으로 두지 않으며, 데이터 사실성·계산 정확성·사후 평가의 정직성은 유지한다.

## What Changes

- `predict -> independent investor-analysis -> risk snapshot -> portfolio-report` 흐름을 유지하되 최종 단계에 근거를 갖춘 포트폴리오 판단을 추가한다. 정량 순위·다수결·confidence 곱은 최종 추천의 자동 결정식에서 진단 자료로 낮춘다.
- 개별 주식과 ETF를 동등한 대안으로 비교한다. 지수 ETF의 자동 우선 선택이나 개별 주식의 자동 우월 가정을 두지 않는다. 매수·유지·축소·대기 판단, 가격 가정, 반증 조건, 비중 근거를 남긴다.
- 추천 가능 상태와 성과 검증 상태를 분리한다. `prior_only`와 OOS 부재만으로 추천을 중단하거나 주식 비중을 자동 축소하지 않는다. 검증 결과는 판단을 개선하는 근거이며 미래 성공의 보증서가 아니다.
- 현금 비중은 지출 필요액·통화·기회비용·투자 대안·시장 위험을 함께 검토해 결정한다. 기계적 배분 후 남는 잔액은 별도의 계산 잔액으로 표시하고 완성된 현금 전략으로 제시하지 않는다.
- 추천 시점의 데이터, 입력 가정, 선택한 비중, 비교 기준과 재검토 조건을 고정해 저장하고, 이후 자료로 사후 평가한다. 좋고 나쁜 성과 모두 기록하며 과거 추천을 소급 수정하지 않는다.
- **BREAKING (스킬의 기본 실행 흐름):** 새 추천에는 사용자 맥락과 최종 판단 입력이 추가된다. 기존 점수 배분 CLI와 JSON은 명시적인 legacy 경로로 보존하여 이미 만든 보고서를 재현할 수 있게 한다.

## Capabilities

### New Capabilities

- `portfolio-decision`: 사용자 맥락, 기업·ETF별 근거, 독립 분석, 위험 자료를 종합한 현재 추천과 주식·ETF·현금 비중의 검증·직렬화.
- `portfolio-decision-evaluation`: 변경 불가능한 추천 스냅샷과 구성 후 성과·투자 가설 검토를 연결하는 사후 평가 계약.

### Modified Capabilities

없음. 기존 `agent-os-control-plane` 요구사항은 유지한다. 적용 단계에서 현재 작업 연결과 정책 설명을 갱신하되, 기존 `point-in-time-evidence-gates`의 미완료 증거 수집 작업은 보존한다.

## Impact

- `.agents/skills/{predict,investor-analysis,portfolio-report,backtesting}/SKILL.md`와 관련 참조 계약, 실제 `.claude/skills` 미러 구조.
- `portfolio-report/scripts/generate_portfolio_report.py`, 위험 스냅샷의 ETF 대상 지원, 새 판단 입력 검증·사후 평가 코드, CLI·JSON·엑셀·텍스트 보고서.
- `AGENTS.md`, `README.md`, `openspec/config.yaml`, `.agent-os/manifest.json`의 연구 추천 목적과 검증 게이트 설명. 검증되지 않은 성과를 사실처럼 표현하는 금지는 유지한다.
- 기존 `tests/test_financial_skills.py` 및 새 판단·사후 평가 회귀. 새 유료 서비스·외부 LLM API 의존성은 요구하지 않는다.

### Evidence and constraints

- 설계 기준일: 2026-09-09. 사례 입력은 `portfolios/sp500_20260909`의 2026-09-08 미국 종가까지 Yahoo 가격·현재 재무, 독립 분석 90건, 위험 스냅샷이다. 새 실시간 추천 실행은 이번 제안의 산출물이 아니다.
- 개별 기업 자료는 기업 공시/IR, ETF 자료는 운용사의 구성·수수료·기준일, 금리 자료는 공식 기관을 우선한다. 조회일·재무 결산일·공시일을 구분한다.
- 인증 누락, timeout, quota, stale, revision, schema 불일치와 실제 0을 구분한다. 원천의 필수 가격·식별자·구조화 판단이 잘못되면 해당 입력을 거부하고, 사용 가능한 대안의 추천은 계속할 수 있다.
- 합계 100%, 사용자 지출 제약, 단일 주식·ETF·섹터·중복 보유 한도, 매매·환전 비용을 검증한다. ETF에 개별 회사 상한을 그대로 적용하지 않으며 한도와 적용 단위를 기록한다.
- 기대 근거: 입력 스냅샷과 중간 판단, 결정론적 비중 검사, JSON 왕복·보고서 일치, 구성 후 평가 시점 검사. 이 근거를 실현 초과성과 증거로 승격하지 않는다.
- 장기 전략 목표와 개별 사용자의 1~3년 자금 사용 가능성은 별도 입력이다. 목표가 높다는 이유로 유동성 제약을 삭제하지 않는다.

### Non-goals

- 실제 거래·자금 이동, 수익 보장, 특정 투자자의 성과 재현 보장, 유료 provider 활성화, 외부 게시·메시지·자동 스케줄 생성.
- 뉴스 감성 점수를 검증 없이 정량 순위에 반영하거나, 현재 재무를 과거 빈티지로 바꾸는 것.
- 이번 스킬 개선만으로 장기 성과 우위·예측 정확도 향상을 입증했다고 주장하는 것.
- 기존 S&P 500/KRX 보고서·사용자 변경·기존 OpenSpec의 미완료 검증 작업을 덮어쓰는 것.
